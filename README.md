# TaskFlow 📝

A simple, full-stack **MERN Task Manager** to organize tasks, track progress, and stay productive.

### ✨ Features
- Create, edit, and delete tasks
- Track task status
- Clean, responsive user interface

### 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

### 🚀 Run Locally
```bash
# Start the backend
cd backend
npm install
npm start

# Start the frontend in a new terminal
cd frontend
npm install
npm run dev
```

Configure the environment variables using the provided `.env.example` files.
